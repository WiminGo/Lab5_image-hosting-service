# MVP (Minimum Viable Product)

## Обзор

MVP проекта **Image Hosting Service** — каркас веб-приложения для организации изображений в альбомы. На данном этапе реализована клиентская часть с mock-данными, полноценный UI и структура для будущего подключения серверного API.

## Функциональные требования

- **FR-1**: Просмотр списка альбомов на главной странице (карточки с обложкой, названием и счётчиком изображений).
- **FR-2**: Создание нового альбома через форму с полем "Название".
- **FR-3**: Просмотр галереи изображений выбранного альбома (`/album/:id`).
- **FR-4**: Полноразмерный предпросмотр изображения (`/image/:id`) с кнопкой возврата.
- **FR-5**: Загрузка изображения с выбором файла, названием и выбором целевого альбома (`/upload`).
- **FR-6**: Клиентская SPA-навигация через React Router (маршруты: `/`, `/album/:id`, `/upload`, `/image/:id`).

## Use Cases

### UC-1: Просмотр списка альбомов
1. Пользователь открывает `/`.
2. Видит заголовок "Мои альбомы", кнопку "+ Создать альбом" и сетку карточек.
3. Каждая карточка содержит обложку, название и количество изображений.

### UC-2: Создание альбома
1. Пользователь нажимает "+ Создать альбом".
2. Вводит название и нажимает "Создать".
3. Альтернатива: нажатие "Отмена" скрывает форму.

### UC-3: Просмотр галереи
1. Клик по карточке альбома → переход на `/album/:id`.
2. Отображается название альбома, количество изображений и сетка карточек.

### UC-4: Предпросмотр изображения
1. Клик по карточке изображения → переход на `/image/:id`.
2. Отображается изображение в полном размере и кнопка "Назад к альбому".

### UC-5: Загрузка изображения
1. Переход на `/upload`.
2. Заполнение формы: выбор файла, название, выбор альбома из списка.
3. Нажатие "Загрузить" → обработка данных.
4. Альтернатива: не выбран альбом → сообщение об ошибке.

## Границы MVP

### Реализовано
- Просмотр списка альбомов с карточками.
- Создание нового альбома (интерфейс + mock-обработка).
- Просмотр галереи и полноразмерный предпросмотр.
- Загрузка изображения с выбором альбома (интерфейс + mock-обработка).
- SPA-навигация через React Router.
- UI-библиотека с тестовым покрытием ≥ 70%.
- Mock-данные для демонстрации.

### Не реализовано (следующие итерации)
- Авторизация и регистрация.
- Реальная загрузка файлов на сервер.
- База данных.
- Пакетная загрузка.
- Редактирование/удаление альбомов и изображений.


## Нефункциональные требования

- TypeScript со строгими настройками (`strict`, `noImplicitAny`, `noUnusedLocals`, `noUnusedParameters`).
- Запрет `any`, `var`, `require`, `module.exports`.
- ESLint без предупреждений и ошибок.
- Покрытие тестами UI-библиотеки ≥ 70%.
- Сборка без ошибок через `npm run build`.
- Стек: React 19, React Router 7, Vite 5, TypeScript 5.3.3.
